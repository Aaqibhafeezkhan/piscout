piscout

Find and manage your Raspberry Pis from one Windows window. 在一個 Windows 視窗裡，找到並管理你的樹莓派
📡

Auto scan verified

自動掃描

Scans the LAN on launch and recognizes Raspberry Pis. No IP hunting in router pages.

⌨️

Built-in SSH terminal verified

內建 SSH 終端機

Click Connect, enter the login, get a terminal inside the app. No extra window.

🖥️

Remote desktop verified

遠端桌面

See and control the Pi desktop through an SSH tunnel. Nothing exposed on the network.

📊

Fleet overview verified

多台總覽與批次操作

Temperature, load, memory of every Pi at a glance. Reboot, shut down or update many at once.

🔐

Saved logins

加密記住帳密

Encrypted with Windows DPAPI, stored only on your PC. Pi model detected automatically.

🌐

Bilingual UI

雙語介面

Follows your system language (中文 / English), switch any time.

💾

SD card flashing verified

SD 卡燒錄

Official Raspberry Pi OS images, SHA-256 verified, with a recommended OS for your model.

♻️

Remote re-imaging advanced · off by default

遠端重灌（進階）

Re-image a Pi's SD card over SSH without removing it. Real risks, read Known risks first.
